## PROFOUND_ms.R
Contains the R script used to prepare abundance matrix, perform microbiome analysis and make the figures used in the manuscript.
Files used for this includes: Stool_metadata.txt and 16SSequenced_complete-metadata.csv.This script is mainly descriptive analysis. 
We have included the Qiime2 artefacts (*qza) and abundance matrix. 16SSequenced_complete-metadata.csv contains basic metadata information.

## Metagenomics_heatlhy-vs-pfnd.R
Shotgun metagenomic analysis of samples.

## BaselineStool_metadata.txt
Contains the metadata of samples submitted for 16S rRNA gene amplicon sequencing (targeting V4 region).
